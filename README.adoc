= Amath: AsciiMath parser for Ruby

== Purpose

Amath is a parser for https://asciimath.org[AsciiMath], the plain-text
notation for mathematics. It turns input like this into a parse tree:

[source]
----
sum_(i=1)^n i^2 = (n(n+1)(2n+1))/6
----

The tree records the structure of the formula: which symbols, fractions,
roots, sub- and superscripts, matrices and brackets it contains, and how they
nest. Your code decides what to do with it, such as rendering, converting or
analysing it.

== Grammar

The AsciiMath grammar will be written in PARG, the grammar language of
https://github.com/parsanol/parsanol-ruby[Parsanol], and compiled into a
checksummed artifact that the gem loads at runtime. The repository will hold:

* `grammars/`: the grammar source.
* `artifacts/`: the compiled artifact.
* `corpora/`: conformance cases with the input and the tree it must produce.

== Installation

Amath has not been released to RubyGems yet. Until it is, use it from Git in
your `Gemfile`:

[source,ruby]
----
gem "amath", github: "plurimath/amath"
----

Amath needs Ruby 3.2 or later. Its only runtime dependency is
https://github.com/parsanol/parsanol-ruby[Parsanol].

== Usage

[source,ruby]
----
require "amath"

tree = Amath.parse("x_y")
# => {expr: {sequence: {symbol: "x"@0}, expr: {symbol: "_"@1, ...}}}
----

The result is a Parsanol tree: hashes and arrays whose leaves are
`Parsanol::Slice` objects. Each leaf knows its text and where it starts in
the input. Empty input gives back an empty string.

Numbers use a dot as the decimal marker unless you say otherwise. A comma and
the Arabic decimal separator are also supported:

[source,ruby]
----
Amath.parse("1,5", decimal: ",")
Amath.parse("1\u066B5", decimal: "\u066B")
----

Input that is not valid AsciiMath raises `Amath::ParseError`, which tells you
where the parser gave up:

[source,ruby]
----
begin
  Amath.parse("x 1.")
rescue Amath::ParseError => e
  e.char_offset # => position in characters
  e.byte_offset # => position in UTF-8 bytes
end
----

Amath uses Parsanol's fast native engine where it is available and its pure
Ruby engine elsewhere. You can choose one with `engine: :native` or
`engine: :ruby`; asking for the native engine where it cannot run raises
`Amath::EngineUnavailable` rather than quietly using Ruby.
The native engine has a recursion limit (roughly 100 levels of nested
brackets); by default amath parses deeper input with the Ruby engine, while
`engine: :native` raises `Amath::NestingTooDeep`, a kind of
`Amath::ParseError`.
`Amath.last_engine` tells you which engine handled the last call.

The exact rules for trees, positions, engines and errors are in
link:docs/parser-contract.adoc[the parser contract].

== Status

Amath parses all of Plurimath's AsciiMath: Plurimath uses it for AsciiMath
input
(https://github.com/plurimath/plurimath/issues/494[plurimath/plurimath#494]).
It also reads the measurement-uncertainty forms `ustd(...)`, `uexp(...)` and
`ucov(...)` that Plurimath turns into uncertainty nodes
(https://github.com/plurimath/plurimath/issues/493[plurimath/plurimath#493]).

It has not been released to RubyGems yet.
